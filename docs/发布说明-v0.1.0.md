# AgentRelay v0.1.0 首版发布说明

AgentRelay（接力）是面向 DeepSeek Harness 的任务编排与验收插件，附带 HTML 任务图。首版功能已冻结，安装启用后默认待机，由一个 Lead 组织团队子代理执行开发与测试任务。

Harness 提供子代理创建、模型执行、消息投递、会话历史与恢复；AgentRelay 提供任务依赖与认领、自动推进、交付验收、返工记录和任务可视化。任务拆分与验收判断由 Lead 模型完成。

2026-11-06 文档修订：澄清宿主与插件的职责、团队成员身份和查看入口。v0.1.0 执行包及下列校验值保持不变。

包内 bundle 标识为 `dynamic-task-scheduler`，ZIP 内安装说明仍使用原文件名 `安装说明.md`。

## 功能

- 显式加载，根据任务生成计划、成员分工和 HTML 流程图。
- 全部计划内成员回复就绪后，按依赖与资源约束自动派发。
- 连续领取任务，通过宿主向等待成员投递委托并恢复原团队子会话。
- 验收、返工与已接受产物保留，支持追加和调整未派发任务。
- 结束后返回待机，保留任务、交付物和运行历史。

## 成员会话

无需手动创建普通项目对话。Lead 通过调度工具创建团队子代理；只有当前团队内同名成员可以复用，独立普通对话不会自动绑定。默认使用 `fresh` / `spawn`，不复制 Lead 聊天历史；任务要求通过计划、任务卡和委托传递。

在支持的 Harness 界面中，从 Lead 会话头部的子智能体目录打开实际成员，或选择“在侧边栏打开”。

## 下载与安装

下载 ZIP 和 SHA256 文件，解压到要保留的目录。完整退出 Desktop 后，通过宿主 CLI 安装其中的主插件目录。

```powershell
dsh plugin --profile desktop add "<解压目录>/harness/bundle"
```

profile 名称按实际情况填写，使用与 Desktop 相同的 DSH_HOME。`dsh` 指宿主提供的 CLI，未加入 PATH 时使用其实际启动器路径。安装可能建立指向 bundle 的 junction，需要保留解压目录。

按随发行提供的 `INSTALL.zh-CN.md` 配置 agent-team 和 `onDemand:true`，重启后在项目会话输入“加载调度器”，再说明任务。下载者无需 npm 或重新编译。默认模式由主插件维护流程图。

ZIP 是验收时冻结的产物，最新的 CLI 安装补充和验证范围以本说明及随发行提供的 `INSTALL.zh-CN.md` 为准。

## 验证范围

- Windows Desktop 0.2.1-rc.3、Node 24.21.0。
- 本地151项检查通过，解压85个文件哈希一致。
- 解压副本和通过CLI实际安装后的测试profile，均完成冷启动和本地mock启动闭环。
- 单成员就绪期间无派发，全员就绪后两个任务自动完成，原会话恢复。

本轮安装验证使用 CLI 插件管理通道。Desktop `plugin_manager / install_bundle` 工具直接调用、其他机器及其他宿主版本未在本轮验证。模型对“加载调度器”的自然语言选工具过程未实测，启动动作与成员工具管道使用本地mock完成验证。
