# rework-01 任务卡

工作副本在仓库根的 `.scheduler/trials/rework-01/app`。使用 Node.js 自带的测试运行器。产物引用以仓库根为基准，测试命令从 `app` 运行。

业务需求是实现 `normalizeLabels(labels)`。输入为字符串数组，每项先 `trim()`，丢弃空白项，以 `toLowerCase()` 后的字符串作为去重键，保留首次出现项去掉两端空白后的拼写及顺序。返回新数组。例中 `['Urgent', 'urgent', ' Later ', 'LATER']` 应得到 `['Urgent', 'Later']`。

工作副本从已知有缺口的 v1 开始。v1 对大小写敏感，旧行为的五项测试通过，但不满足上述新增要求。第一轮交付用于确认契约和冻结基线，返工阶段才修复该缺口。

## D1 开发

**第一次领取。** 根据业务需求写 `contract.md`，写清接口、去重键、顺序和示例。以 `status:"checkpoint"` 提交 `contract`，随后运行 v1 旧测试，将命令、退出码和输出保存在 `evidence/developer/`。以 `status:"completed"` 提交现有 v1 实现引用，任务进入 review，结束回合。保留 seed 内容和 v1 文件字节。

- `contract` 引用 `.scheduler/trials/rework-01/contract.md`
- `implementation` 首轮引用 `.scheduler/trials/rework-01/app/src/labels-v1.mjs`

**返工领取。** 记录 `scheduler_next` 实际返回的 `attemptId`、`acceptedOutputs.contract`、`rework.previousAttemptId` 和 `rework.feedback`。阅读 Q1 原始失败证据，仅在 `app/src/labels-v2.mjs` 实现修复。保持同一导出，保留已接受契约、v1 和 QA 测试字节。以 v2 跑相同的旧测试和契约测试，将证据写入 `evidence/developer/` 的独立文件。通过后以 `status:"completed"` 只提交新版 `implementation` 引用 `.scheduler/trials/rework-01/app/src/labels-v2.mjs`，结束回合。已接受的 `contract` 随任务保留。

## Q1 独立测试

从领取结果取 `D1/contract` 的已接受引用，读取契约并记录文件 SHA256。依据契约独立编写 `app/tests/contract.test.mjs`，用 `node:test`、`node:assert/strict` 和 `./implementation.mjs` 的 `normalizeLabels`，编写一个混合大小写和空白的断言。运行旧测试与新增测试，验证 v1 原始行为仍通过，新增用例因标签重复而失败。将命令、退出码、原始输出、期望与实际值、契约和 v1 哈希保存到 `evidence/initial/`。

以 `status:"completed"` 提交 `.scheduler/trials/rework-01/evidence/initial/report.md` 作为 `initial-report`，摘要明确写“首测报告完成，契约测试失败”，随后结束回合。若失败原因是环境、语法或测试有误，先记录具体阻断。若 v1 已符合契约，记录未触发返工并交 Lead 判定。

## Q2 最终复测

D1 整项通过且 Q1 已完成后，使用同一测试文件以 v2 复测。核对契约、v1 和契约测试的 SHA256 与首轮记录一致，实际测试全部通过才以 `status:"completed"` 交付 `.scheduler/trials/rework-01/evidence/final/report.md`。最终失败时保存原始证据并报告 failed，结束试用。

## 测试命令

PowerShell 中设定 `REWORK_01_IMPL`，选择同一套测试加载的实现。第一次开发者交付时只运行 `tests/legacy.test.mjs`。从 Q1 起用下面的完整命令，首测选 `v1`，返工与复测选 `v2`。各阶段分开保留 `stdout`、`stderr` 和退出码。

```powershell
$env:REWORK_01_IMPL = 'v1'
try {
  node --test tests/legacy.test.mjs tests/contract.test.mjs
  $testExit = $LASTEXITCODE
} finally {
  Remove-Item Env:REWORK_01_IMPL -ErrorAction SilentlyContinue
}
$testExit
```
